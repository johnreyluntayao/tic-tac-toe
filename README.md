# Tic-Tac-Toe

React + Next.js App Router project with TypeScript and Tailwind CSS v4.

## Current scope

Foundation only. The starter screen and branding have been removed. The home
route intentionally renders only the global background; game components and
logic will be added in the next phase.

## Development

```sh
npm install
npm run dev
```

```sh
npm run build
npm start
```

`npm run lint` runs ESLint. The production build also checks TypeScript.
Inter is loaded through `next/font/google`, which needs network access at build time.

## Theme

The theme follows Johnrey's portfolio: Inter typography, a navy gradient backdrop,
blue and violet accents, and reflective glass surfaces.

- `app/globals.css`: global styles, semantic color tokens, Tailwind theme mappings,
  responsive panel radius, page gutters, focus states, and reduced-motion support.
- `styles/glass.css`: portfolio glass treatment, gradient borders, reflections,
  mobile blur, reduced-transparency support, and fallback styles.
- `app/layout.tsx`: font and page metadata.
- `app/page.tsx`: empty route reserved for the upcoming game.

Future markup can use `glass-container` with optional `glass-accent`, and
`page-container` for centered responsive spacing. Tailwind utilities include
`bg-background`, `text-foreground`, `text-muted-foreground`, `text-accent`,
`text-accent-secondary`, and `rounded-panel`.

The glass styles do not include the portfolio's pointer-tracking glow component.
No components, game logic, extra UI dependencies, or deployment are included yet.

## Project structure

```text
app/
  globals.css       Global theme and base styles
  layout.tsx        Root document, font, metadata
  page.tsx          Empty home route
styles/
  glass.css         Shared glass surface styling
```

Root configuration files support Next.js, Tailwind, TypeScript, and ESLint.
`node_modules/` contains installed dependencies; `.next/` contains generated
build output. Both are ignored by Git. `next-env.d.ts` is generated by Next.js.
The lockfile is retained for reproducible installs. An asset folder can be added
when actual assets are needed; there are no empty placeholder folders.
